# 🚀 What I Do

- Design and architect zero-trust multi-cloud platforms across **AWS, Azure, and GCP** using modular Terraform and OpenTofu
- Harden multi-tenant enterprise **Kubernetes (EKS/AKS/GKE)** clusters with Cilium eBPF network policies, strict Pod Security Standards (PSS), and admission control validation (Kyverno / OPA Gatekeeper)
- Standardize automated **Shift-Left DevSecOps** quality gates — embedding SAST, DAST, SCA, secrets scanning, and vulnerability scoring into developer workflows
- Fortify software supply chains to **SLSA Level 3+** through automated SBOM generation (Syft/SPDX), provenance attestation, and cryptographic signing (Cosign / Sigstore)
- Automate continuous compliance evidence collection and governance against **SOC 2 Type II, ISO 27001, PCI-DSS, NIST 800-53, and CIS Benchmarks**
- Implement enterprise GitOps-based continuous delivery and progressive rollouts using **ArgoCD, Flux, Helm, and Kustomize**
- Design centralized observability & SecOps telemetry utilizing **Prometheus, Grafana, Datadog APM, Splunk Enterprise**, and kernel threat detection with **Falco**
- Architect **Agentic AI** workflows for autonomous infrastructure remediation, automated incident triage, self-healing pipelines, and intelligent code generation
- Lead **Cloud FinOps** initiatives — automated workload rightsizing, commitment discount optimization, waste elimination, and real-time cost governance
